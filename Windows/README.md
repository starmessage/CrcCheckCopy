## CrcCheckCopy: Compare folders on Windows

CheckCopy is a free professional command line utility that lets you compare folders and verify large numbers of files by their CRC hashes. It has a Windows and MacOS edition.  
This is the Windows edition that you can run from the Windows shell/command prompt.
From version 2.8 the Windows edition is compiled into 64bit to handle huge amounts of data. The 32bit might have problems due to the Windows memory limits for 32bit programs. However if you need it, the 32bit edition is also available as CrcCheckCopy32.exe.

See examples of the command line syntax at our website: [Compare folders on Windows](https://www.starmessagesoftware.com/crccheckcopy/how-it-works#compare-folders-windows-10)
